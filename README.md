# GDConvert

GDconvert is a tool i made to avoid learning FFMPEG and YT-DLP that caused me to learn them instead because im stupid

GDconvert is a tool for Converting, Compressing, And Downloading files. It was created because i used like 5 diffrent tools to accomplish what  i can do with just this one.

## Installation 

Download the approriate file from the releases and run it.

## features

Convert from video to image and aduio and vice versa

compress video including with a funny bit crusher setting for shitposting

download youtube videos and playlists.
